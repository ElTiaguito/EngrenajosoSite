Sobre o jogo

Engrenajoso é um projeto acadêmico desenvolvido para o PI do 4º Semestre, onde o jogador deve montar robôs, interagir com peças mecânicas e resolver desafios dentro de uma oficina.

O jogo mistura montagem, lógica e interação com clientes, criando uma experiência divertida e dinâmica.

Mecânicas do jogo

Montagem

Encaixe as peças e faça combinações para montar os robôs da maneira certa.

Fios

Resolva desafios conectando os fios corretamente para concluir a montagem.

Clientes

Atenda e dialogue com clientes de vários tipos.
